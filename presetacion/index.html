Contexto del Proyecto

Refrigeración y Motores Industriales

Este proyecto busca predecir fallas en sistemas de refrigeración y motores eléctricos utilizados en industrias del Valle de Aburrá.

  • Aplicación: Cámaras de frío, centros de datos, líneas de producción.
  • Riesgo: Sobrecalentamiento y daño del motor.
  • Objetivo: Detectar anomalías antes de que ocurra la falla.
Sistemas de Refrigeración Industrial

Fase 1

Obtención de Datos

El modelo se alimenta de datos continuos capturados directamente del sistema.

  • Sensores: Temperatura del refrigerante, vibración del motor, voltaje y corriente.
  • Históricos: Registros de fallas, mantenimientos y paradas.
  • Contexto: Tipo de carga, horario y condiciones ambientales.
Sensores y Motores

Fase 2

Limpieza y Validación

Garantizamos que los datos representen el comportamiento real del sistema.

  • Imputación: Uso de mediana para evitar sesgo por picos.
  • GIGO: Eliminación de lecturas erróneas del sensor.
  • Validación: Rangos físicos de operación seguros.
Data Cleaning

Fase 3

Análisis de Anomalías

Analizamos cómo se comporta un motor sano frente a uno defectuoso.

  • Patrones: Temperatura estable vs incrementos anómalos.
  • Voltaje: Caídas o picos fuera de lo normal.
  • Vibración: Indicador temprano de desgaste mecánico.
Análisis Exploratorio

Fase 4

Ingeniería de Características

Transformamos señales crudas en información útil para el modelo.

  • Variables: Promedios móviles y desviaciones.
  • Etiquetas: Normal vs anomalía.
  • Tiempo: Ventanas temporales para predicción.
Feature Engineering

Fase 5

Modelo y Fine-Tuning

Entrenamos y ajustamos el modelo para el entorno real.

  • Regresión: Predecir temperatura y consumo.
  • Clasificación: Detectar estado normal o falla.
  • Fine-Tuning: Ajuste con datos locales.
Modelo Predictivo

Cierre

Predicción de Fallas

El sistema permite actuar antes de que ocurra el daño.

  • Beneficio: Menos paradas inesperadas.
  • Ahorro: Reducción de costos de mantenimiento.
  • Impacto: Mayor confiabilidad operativa.
Conclusión
